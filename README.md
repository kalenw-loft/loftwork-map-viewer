# Loftwork Map Viewer

An explorable 3D map of everything published on loftwork.com (projects, findings, events, news), organised by the part of society each piece touches.

Open the live site at GitHub Pages. Each dot is a page on loftwork.com; click one to see its links, related work, and the people credited.

This repository holds only the static viewer (`index.html`, `data/items.json`, `thumbs/`). Data was collected from public sitemaps and pages. Positions are placeholders and the map is an early prototype.

Trackpad: two fingers sideways orbit, up and down move through the years, pinch zooms toward the cursor, Shift + two fingers pans.
